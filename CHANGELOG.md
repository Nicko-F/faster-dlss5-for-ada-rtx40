# Changelog

## 0.2.0 automatic dimensions — private review, 2026-09-10

- One installation, native runtime dimensions, no resolution selector.
- General variants for four dimension-folded sites; automatic exact-size fast paths.
- 16:10, ultrawide, odd-size, motion and NR+SR correctness checks.
- Status accepts mixed observed sizes; known v0.1 installations remain removable.
- Existing timing tables remain v0.1; no new performance benchmark.


## 0.1.0 source preview — private review, 2026-09-10

- English and Chinese project pages with explicit community baseline credits.
- Per-run NR/game measurements, table calculator and qualified 5070 Ti reference.
- Original Windows manager for compatibility checks, profile installation, launch,
  routing verification and removal; missing acceleration payload is explicit.
- Authored V1 API declaration, MIT license, dependency notices and contribution guide.
- Source allowlist, archive audit and install/recovery tests.

No public GPU accelerator binary is included. The complete local test package is
separate and has no established permission basis for public redistribution.
