# Faster DLSS5 for Ada / RTX 40

**让 Ada 上的社区 DLSS5 神经渲染更快，并公开可以复算的性能数据。**

[English](README.md) · [优化方法](docs/optimizations.zh-CN.md) · [完整测试口径](docs/benchmarks.zh-CN.md) · [安装指南](docs/install.zh-CN.md)

已测 v0.1 版本在 RTX 4080 上的 4K 纯神经网络推理降耗时为 **8.16%（独立运行）/ 10.30%（交替对照）**；《赛博朋克 2077》4K 游戏平均 FPS 比测试所用社区版提升 **4.20%**。

**当前先放在 Private 仓库审阅，为源码与工具预览，尚无公开的开箱即用加速包。** 完整加速包已经作为本地测试版本整理，但其中 GPU 内核来自修改后的 NVIDIA 代码，尚未找到覆盖其分发的授权依据。因此公开源码目录不含这些内核；仅下载这里的工具不会产生加速。[发布内容与许可状态](docs/distribution.zh-CN.md)。

## 优化了什么

**这是叠加在可用社区 base 上的加速补丁。** base 继续负责运行库、模型、游戏接入、
资源准备、分辨率和原有兼容适配。完整本地补丁只增加我们的插件与选用的优化内核，
不匹配优化契约的调用保留 base 执行。这里的适配工作只覆盖加速补丁自身的执行要求，
不承担重做社区栈全部兼容性的任务。

1. 异步搬运：把适配后的拷贝组织成仍可重叠执行的流水，减少不必要的逐次等待，保持原有生产者/消费者依赖。
2. 寄存器压力与 spill：缩短变量活跃区间、将 fragment 加载移近使用位置，调整融合投影、Attention、FFN 的寄存器预算，消除部分入口的栈访问。
3. Uniform/scalar lowering：兼容转换会改变部分指令的寄存器分配压力。**不能解释成“40 系没有 uniform register”，也没有证明全部 spill 都由这一点导致。**
4. Shared memory 与执行调度：只保留已测得收益的 shared staging / spill 策略，自动按运行库的层尺寸选择执行变体；不是把所有溢出一律搬到 SMEM。
5. Pre/Post：在输出格式、形状和历史帧条件匹配时启用前后处理优化。

我们保留 NVIDIA 的数学和数据依赖语义，针对 Ada 调整执行组织。现有数据对应实验版本，不承诺所有显卡和游戏都有同等收益。

## 纯 NR GPU 推理

以下耗时表来自冻结的 v0.1。v0.2 增加自动尺寸支持，另有正确性验证；尚未重跑游戏或性能 benchmark。

RTX 4080、驱动 616.56、Ryzen 9 9950X；固定合成输入、model1/sRGB，每次预热 100 帧、测量 400 帧，每行汇总两次运行。

| 分辨率 | 方法 | 社区 ms | 优化 ms | 降耗时 |
|---|---|---:|---:|---:|
| 1080p | 独立运行 | 4.8164 | 4.5786 | 4.94% |
| 1080p | 交替对照 | 4.7539 | 4.4994 | 5.35% |
| 1440p | 交替对照 | 7.5083 | 6.8246 | 9.11% |
| 4K | 独立运行 | 18.2810 | 16.7892 | 8.16% |
| 4K | 交替对照 | 17.6821 | 15.8614 | 10.30% |

独立运行取两次 P50 的平均，交替对照取两次各 arm 均值的平均。1440p 暂无独立运行性能对照；4K 交替绝对耗时有漂移，两轮均保留。交替运行共享历史，不能替代独立正确性验证。

## 游戏内结果

《赛博朋克 2077》2.31 官方 benchmark，High raster、原生 DLAA、SDR，关闭 RT/PT/RR/FG/DRS/Reflex/VSync 和帧率上限。每个分辨率、每个版本两次；原游戏不加载实验 NR/ReShade 栈。

| 分辨率 | 原游戏 FPS | 社区 DLSS5 FPS | 优化 DLSS5 FPS | 相对社区 FPS 提升 |
|---|---:|---:|---:|---:|
| 1080p | 179.57 | 91.37 | 92.62 | 1.36% |
| 1440p | 134.78 | 66.77 | 69.50 | 4.10% |
| 4K | 64.66 | 31.08 | 32.38 | 4.20% |

1080p 两组配对提升为 0.42% / 2.33%，此前完整批次为 0.40%，暂不宣称稳定的固定收益。GPU 未锁频；不同分辨率是各自完整批次，不能当成同一轮连续测试。

## 游戏新增耗时与公开 5070 Ti 参考

逐次计算 `1000/FPS`，同版本取平均，再减去同批原游戏帧时间。结果是开启 DLSS5 增加的整帧成本，包含插件接入、同步和资源竞争，**不是纯网络 GPU 计时**。

| 分辨率 | 社区新增 ms | 优化新增 ms | 节省 ms | 相对社区降成本 | 5070 Ti 外部参考 ms |
|---|---:|---:|---:|---:|---:|
| 1080p | 5.377 | 5.228 | 0.148 | 2.76% | — |
| 1440p | 7.558 | 6.968 | 0.590 | 7.80% | 7.8 |
| 4K | 16.714 | 15.416 | 1.298 | 7.77% | 17.0 |

5070 Ti 数据来自 [TechSpot / Tim Schiesser，2026-09-04](https://www.techspot.com/article/3170-real-dlss-5-performance/)，使用《NBA 2K27》官方集成。我们的 1440p / 4K 新增成本估算值在数值上低 10.66% / 9.32%，但游戏、接入和软件平台不同，**不是同条件验证“4080 比 5070 Ti 快约 10%”**。原文耗时表未给出 1080p，不补造数据。

## Base、使用与持续更新

游戏 base 明确为 **ReShade 6.8.0 addon support + RenoDX DLSS5 addon 4.70 + 社区修改的 NR 310.8.0**。实验室使用 AIO / DLSS5-Feeder 的固定版本，不能把它们与游戏插件混称。[文件身份](compatibility/baseline.json)与[来源说明](THIRD_PARTY_NOTICES.md)随仓库提供。

双击 `Start.cmd` 可打开兼容性检查、安装、启动、验证和卸载菜单。公开源码预览缺少 GPU payload；安装与启动优化需要完整本地包。v0.2 完整本地包一次安装，自动沿用 DLSS5 传入的尺寸与 padding，包含已检查的 16:10、超宽屏和非整齐尺寸，无需手选分辨率。验证样本不是白名单；具体范围见[动态尺寸验证](docs/dynamic-dimensions.zh-CN.md)。已测硬件与游戏范围仍为 RTX 4080 / 驱动 616.56 / CP2077 2.31、SDR。其他 40 系、新驱动、HDR 或其他游戏仍待测试。工具不会覆盖未知插件，不分发运行库或权重。

我们会持续公开新的优化、测试数据、兼容适配和发布记录，欢迎讨论、复测与贡献，不承诺固定更新周期或每张卡的固定提升。Private 仓库已为有访问权限的同事启用 [Issues](https://github.com/Nicko-F/faster-dlss5-for-ada-rtx40/issues) / [Discussions](https://github.com/Nicko-F/faster-dlss5-for-ada-rtx40/discussions)；暂不公开项目。[后续计划](ROADMAP.md)。
