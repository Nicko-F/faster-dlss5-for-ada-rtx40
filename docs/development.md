# Development notes

## Unreleased — private draft, 2026-09-10

The project has not made its first release. Internal preparation rounds are not
release versions. A version number will be assigned when the owner authorizes the
first release. The two mistakenly numbered private previews have been withdrawn;
their code, evidence and local archives are preserved.

- Minimal acceleration patch over the existing community base.
- One installation with native runtime dimensions; no resolution selector.
- General variants for four dimension-folded sites and automatic known-size fast paths.
- 16:10, ultrawide, odd-size, motion and NR+SR correctness checks.
- English/Chinese docs, exact baseline identities and qualified performance tables.
- Reversible manager with recovery for earlier local draft installations.
- Source allowlist, original API declaration, archive audit and tests.

Timing tables belong to earlier fixed-size experimental builds. Automatic-dimension
checks establish final-image agreement and routing, not new performance results.
The complete local GPU patch remains separate from this source draft.
