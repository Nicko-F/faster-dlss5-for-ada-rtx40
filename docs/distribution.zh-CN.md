# 包内容

[English](distribution.md)

加速包包含加速插件、选定的 GPU 内核和中英文安装器。
社区 base 提供 NR 运行库、模型及游戏接入。

本仓库包含我们编写的加速插件、47 个内核配方、PTX 转换工具、调度元数据、
安装器、测试、技术报告和实测结果。[本地构建流程](build.zh-CN.md)使用自己的社区运行库，
生成可安装的完整加速包。源码压缩包不含第三方 PTX/SASS、运行库 DLL、模型权重或已编译的 GPU 内核。

项目原创文件采用 MIT 许可证。第三方组件沿用各自的许可，见[来源说明](credits.md)。
当前派生 GPU 二进制的分发需要相应 NVIDIA 条款下的授权；获得该授权之前，
这些二进制保留在本地加速包中。
