# 一次安装，跟随运行库尺寸

[English](dynamic-dimensions.md)

v0.2 取消安装时手选 1080p、1440p、4K。同一个插件和 GPU 包直接使用 DLSS5
传入的尺寸。16:10、超宽屏不会对应另一套手动配置。

网络有效区域、padding、分块、内存布局、启动网格和标量参数仍由 DLSS5 决定。
我们保留这些原始参数，只在调用契约匹配时替换 GPU 函数，不在安装器里重新分区或缩放图像。

多数保留的优化内核原本已经使用动态尺寸。之前四个调用位置在优化时折叠了高宽常量；
现在补充通用变体，保留动态高宽，仅折叠模型不变量。已测尺寸的专用快速路径仍可在
有效区域及内部尺寸都精确匹配时自动选用，用户无需操作。

## 验证与边界

真实 RTX 4080 验证使用独立的社区与优化进程。静态输入覆盖 1600×1000、1920×1200、
2560×1600、3440×1440、1919×1199，以及原先的 1920×1080、2560×1440、3840×2160。
运动输入覆盖 1920×1200、2560×1600、3440×1440。每组运行三帧，对比最后导出的图像，
并核对替换数量与错误计数。这不是逐个中间张量对比，也不是完整的时序画质评估。

这些尺寸是验证样本，不是安装器白名单。其他尺寸只要原生模型与调用契约匹配，
即可使用通用路径；不匹配的调用保留原生执行，并在日志中体现，不能记为完整加速。
特别大的输入仍受显存和运行库限制，有限样本不能证明所有可能尺寸都正确。

NR 尺寸与最终显示尺寸需要区分。缩放仍归原运行库处理。独立 NR+SR 流水也检查了
1280×800 输入到 1920×1200 输出，但不意味着每款游戏、每种动态分辨率模式都已验证。
切换分辨率无需重装；长时间游戏及游戏内动态切换仍需后续验证。

可替换 145 次内部调用；时序表面契约匹配时另外替换两次 Pre/Post。
首帧或缺少历史的帧保留原生 Pre/Post。本地包只有一个插件和 47 个共享 GPU 文件
（45 个内部变体加两个 Pre/Post），适用于不同尺寸。

硬件、运行库身份、预设和格式检查仍有效。本次推广的是尺寸，不是未经验证的显卡、
驱动、游戏或模式。未来可公开的源码预览仅包含管理工具和结果，私有实现与派生 GPU 文件不包含在内。

其他页面的耗时表继续归属于 v0.1；本轮尺寸验证不代表新尺寸已经测出了相同百分比的性能收益。
